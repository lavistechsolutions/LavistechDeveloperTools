4. WHAT THE TOOLS DO

4.1 The Application provides local utilities for formatting JSON, converting
XML to JSON, encoding and decoding Base64, inspecting JSON Web Tokens,
generating GUIDs, testing .NET regular expressions, hashing text, explaining
five-field cron expressions, and calculating file checksums.

4.2 These tools run on Your computer. The Application does not upload the
text or files You provide.

4.3 The JWT decoder shows the header and payload only. It does not verify
the signature, issuer, audience, or expiry. Do not treat a decoded token
as authenticated.

4.4 Hash and checksum results are for inspection and comparison. They do
not prove authorship, and a matching checksum only shows that the compared
values are the same.

4.5 The cron helper explains the five standard fields. It does not calculate
the next run time, and cron dialects differ.

4.6 Do not paste secrets into the Application unless You accept that they
are then present in the window and may remain in the process until it exits.
The Application is not a password manager or a secrets vault.
