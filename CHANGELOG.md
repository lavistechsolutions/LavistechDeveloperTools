## [1.0.0] - 2026-11-24

### Added
- Initial release of the offline Windows developer toolkit.
- JSON formatter, XML to JSON, Base64, JWT decoder, GUID generator, regex tester, SHA-256 and SHA-512 text hash, five-field cron helper, and file checksum.
- The name shown in the window is Lavistech DeveloperTools.
